# AWS & DevOps Hands-On Labs

A collection of hands-on labs and assignments covering AWS Cloud and DevOps technologies.

## AWS Labs

- **CloudFront** – S3 static website, caching & invalidation
- **DMS** – Database migration using AWS DMS
- **Organizations** – AWS account and organization management
- **Load Balancer** – Application Load Balancer setup
- **Lambda** – Simple serverless function

## Technologies

**AWS | Terraform | Docker | Kubernetes | Jenkins | Ansible | Linux | Git**
